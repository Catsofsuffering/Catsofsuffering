# GrayWar / Ventus

I build security-aware AI and automation systems that make complex workflows easier to inspect, execute, and trust.

My work sits at the intersection of:

- AI agent orchestration and developer tooling
- Security intelligence and data workflows
- Automation, prediction, and decision support

## Selected work

### [CCSM](https://github.com/Catsofsuffering/ccsm)

A Codex-led OpenSpec workflow package that coordinates planning, bounded execution, review, and acceptance across AI coding agents, with a local monitor for workflow visibility.

### [xThreatBook](https://github.com/Catsofsuffering/xThreatBook)

A Splunk App that uses the XThreatBook API to bring threat intelligence into security analysis workflows.

### [iBizSim prediction model](https://github.com/Catsofsuffering/iBizSim-prediction-model)

Automation tooling for an enterprise simulation workflow, including data extraction, spreadsheet updates, and decision submission, with a foundation for prediction models.
